## 函件类型一：工程维修催告函（告知函）

**适用场景**：质保期内承建方迟迟不响应、不进场，需要书面限期警告。

**文件名规范**：`工程维修催告函_WB-CCYZ(EM)-{地块代号}-{年份}-{三位序号}_{责任单位简称}维修.docx`
例如：`工程维修催告函_WB-CCYZ(EM)-A-2026-008_二十冶维修.docx`

**函头格式**（固定格式，**使用正常段落而非表格**，严格对齐）：
```
工程维修催告函（居中，华文宋体，16pt，加粗，无下划线）
（空行）

工程名称： {第一合同全称}             ← 标签run + ：+ 值run（下划线）
{第二合同全称}                        ← 独立行！值run（下划线）+ 空格
编    号： {编号}                     ← 半角空格，标签run + ：+ 值run（下划线）
函件标题： 关于{简述事由}的告知函     ← 值run（下划线）
日    期： 2026年7月26日              ← 年/月/日各为一个下划线run
主    送： {合同全称}      需回复： ☑是   □否    ← ☑□为Segoe UI Symbol，需回复部分不在下划线中
抄    送:  {抄送列表}                   ← 值run下划线+尾部空格
附　　件： {附件描述}              ← 全角空格标签，值run下划线+尾部空格
（空行）
函件内容： （华文宋体，12pt，加粗）
```
> ⚠️ 编号使用**半角冒号+半角空格**`编    号：`，不是全角`编　　号：`
> ⚠️ 全文字体统一使用**华文宋体**（非宋体/仿宋），通过 Normal 样式和 run.rFonts.eastAsia 双重设置

**函头生成规范（字体与排版）**：
- **整体字体**：全文统一使用**华文宋体**（10.5pt默认），Normal样式 + 每个run的eastAsia均设华文宋体
- **标题**：华文宋体 16pt，**仅加粗**，无下划线，居中，正常间距（不设精确spacing）
- **函头标签**：华文宋体 10.5pt/12pt，正常
- **函头值**：华文宋体 10.5pt/12pt，**下划线**（部分拆分run），尾部带空格
- **主送**：☑/□使用 Segoe UI Symbol 字体，"需回复："在值run外面
- **日期**：年、月、日拆分为独立下划线run
- **`函件内容：`标签**：华文宋体 12pt，加粗，与函头间空一行
- **正文**：华文宋体 10.5pt，**不缩进**，**不设精确段间距**（before/after缺省）
- **联系人/签署**：华文宋体 10.5pt，不设精确间距
- **签署**：`经办人：` + 空格 + `盖章：` + 空格，不是审核人

## 编号规则

- 格式：`WB-CCYZ(EM)-{地块代号}-{YYYY}-{NNN}` 其中地块代号根据责任单位所属合同地块确定（详见责任单位对照表），NNN为三位流水号（如008、024）
- 同一地块内编号连续递增
- 用户提供最新编号，或助手询问"上一个编号是多少"以自动推算下一个
- **A地块已使用编号序列**：008、009、010、011、013、014、015、016、017、018、019、020、021、022、023、024（注意012可能跳号）
- **C地块已使用编号序列**：024、041、042、043、044、047、048、049、050、051、052（江苏双楼、五矿瑞和、领航智能、苏州金格、清风逸景）
- **D地块已使用编号序列**：006、007、008、009、011、012、013（中建七局）
- 编号前缀必须与责任单位所属地块对应，**不得混用地块代号**

## 函件生成输出规范

1. **确认地块代号**：根据责任单位所属合同地块确定编号前缀（参考对照表），不得写错
2. **询问缺失信息**：如用户未提供编号、日期、责任单位、问题描述、附件页数，必须先询问
3. **日期格式**：统一用"YYYY年M月D日"（不补零，如"2026年4月8日"而非"2026年04月08日"）
4. **输出归档路径**：`{发函文件根目录}/{所在大类}发函文件/{YYYY年M月D日}/`
   - **A地块** → `发函文件/A地块发函函件/{日期}/`
   - **C地块 / D地块** → 统一归入 `发函文件/CD地块发函文件/{日期}/`
   - 示例（中建七局/D地块）：`发函文件/CD地块发函文件/2026年6月24日/`
   - 示例（江苏双楼/C地块）：`发函文件/CD地块发函文件/2026年6月24日/`
   - ⚠️ C和D共用同一归档目录，A独立归档
5. **文件名**：按各类型规范命名，文件名中编号前缀须与所属地块对应
6. **字体规范**：全文统一使用**华文宋体**；标题16pt加粗无下划线，函头标签/值10.5pt，正文10.5pt
7. **函头格式**：使用正常段落（非表格），标签与值分两个run（标签正常，值加下划线）
8. **函头对齐**：编号用**半角冒号+半角空格**（`编    号：`），主送☑/□用 Segoe UI Symbol，日期年/月/日拆分run
9. **附表文字核对**：若从Excel台账读取数据，注意核对以下常见文字差异：台账中"客厅顶爆灰"应为"客厅顶**棚**爆灰"；"窗台板开裂因墙体开裂导致"应为"窗台板开裂，**因**墙体开裂导致"
