# 精装修检查报告生成工具

## 概述

根据现场查验照片（含水印）自动生成精装修样板联合检查报告（.docx 格式），遵循华东区域璀璨云著项目的标准报告模板。

## 工作流程

### 第一步：接收照片

用户提供一批现场照片（.jpg），每张照片底部含水印信息：
- 项目名称
- 日期时间
- 施工区域（楼栋-房号，如"1-201"）
- 施工内容 / 问题描述
- 地点

### 第二步：OCR 水印识别

使用 `photo-summary-excel` skill 对照片进行水印 OCR 识别，提取：
- 拍摄时间
- 楼栋-房号
- 问题描述文本
- 责任方判定（工程 vs 保洁）

### 第三步：分类与分组

按以下维度整理问题：
1. **按责任方分类**：工程类 / 保洁类
2. **按楼栋房号分组**：同一户的多个问题合并呈现
3. **去重合并**：同一位置同一问题只保留一条

**责任方判定规则：**
| 类别 | 典型关键词 |
|------|-----------|
| 工程 | 油漆、安装、缺失、接缝、划痕、破损、打胶、面板、灯具、地漏、下水、轨道、幕帘、缝隙、不平、毛糙、未封堵、未安装、色差、异色 |
| 保洁 | 灰尘、灰大、污染、未清理、垃圾、保洁、清洁 |

若水印中无明确责任方信息，根据问题描述关键词自动判定。

### 第四步：逐条写入整改建议

对每条问题，生成匹配的整改建议。原则：
- **工程类**：修复、更换、重新安装、打磨粉刷、打胶封堵等具体施工措施
- **保洁类**：清理、保洁、覆盖保护膜等清洁措施
- **语言风格**：简洁直接，可操作，参考模板中的既有写法

### 第五步：生成 .docx 报告

使用 docx skill 按以下模板生成报告：

```
════════════════════════════════════════
华东区域璀璨云著项目
精装修样板联合检查报告

{YYYY年M月D日}
════════════════════════════════════════

一、基本情况
┌──────────┬───────────────────────┐
│ 项目名称 │ {用户指定项目名称}    │
│ 组织部门 │ {用户指定部门}        │
│ 检查日期 │ {检查日期}            │
│ 检查人员 │ {区域公司}            │
│          │ {项目名称}            │
│          │ {部门：人员}          │
│ 项目概况 │ {标段/范围描述}       │
└──────────┴───────────────────────┘

二、检查组总结及管理建议
{总体评价与管理建议}

三、现场检查问题及整改建议

1. 问题描述：（工程）{问题一描述}
   整改建议：{整改措施一}
   [附图：照片_001.jpg, 照片_002.jpg]

2. 问题描述：（保洁）{问题二描述}
   整改建议：{整改措施二}
   [附图：照片_003.jpg]
...
```

### 报告格式要点

1. **标题**：`华东区域璀璨云著项目` + 换行 + `精装修样板联合检查报告`
2. **日期**：大字居中，`YYYY年M月D日` 格式
3. **基本情况**：表格形式，左列字段名右列值
4. **问题编号**：从 1 开始连续编号
5. **问题描述格式**：`问题描述：（{工程|保洁}）{具体描述}`
6. **整改建议格式**：`整改建议：{具体措施}`
7. **照片**：每条问题后直接插入对应现场照片（宽度10cm），不单独标注文件名
8. **同户多问题**：按户分组展示，先工程后保洁

### 输出交付物

1. **检查报告 .docx**：完整格式的报告文件，包含所有现场照片
   - 文件大小约 30-40MB（含 60 张照片）
   - 照片直接嵌入文档，无需额外附件

## 常见用户交互模式

用户可能会说：
- "帮我把这些照片生成检查报告"
- "这里有现场查验照片，按之前的模板写报告"
- "生成精装修检查报告，照片在 XX 目录"
- "按照片生成检查报告，把照片插入进去"
- "按参考报告格式重新生成，插入照片"

此时按工作流程五步执行。用户如未提供"基本情况"字段（项目名称、组织部门、检查人员、项目概况），先使用 OCR 提取的日期作为检查日期，其余字段向用户确认后再填入。

## 技术实现要点

### OCR 识别
- 使用 `easyocr` 库识别照片底部水印
- 水印格式：`施工区域 {楼栋房号} 施工内容 {问题描述} 地点 {位置}`
- OCR 结果存储于 `ocr_results.json`

### 数据清洗
- 区域标准化：修正 OCR 噪声（如 "302" → "10栋1302"）
- 内容去重：使用子串匹配避免重复问题
- 分类规则：根据关键词自动判定工程/保洁

### 照片插入
- 使用 `python-docx` 库插入图片
- 图片宽度设置为 10cm，居中显示
- 如果插入失败，显示文件名作为备选
