# 照片OCR汇总表生成器

将带有水印的检查照片批量处理为结构化Excel汇总表，照片直接嵌入表格中。

## 使用场景

- 空鼓检查照片 → 按户号归档汇总表
- 施工验收照片 → 按楼层/房间归档
- 物业巡检照片 → 按问题分类归档
- 任何需要从照片水印中提取信息并生成汇总表的场景

## 工作流程

### 第1步：确认参数

向用户确认以下信息（有默认值的可不问）：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| **照片目录** | 照片所在文件夹路径 | 无，必问 |
| **输出路径** | Excel文件保存路径 | 同照片目录下 `X栋空鼓检查汇总表.xlsx` |
| **楼栋名称** | 如"3栋"、"A区" | 从文件夹名自动推断 |
| **排序方式** | 户号降序/升序 | 降序 |

### 第2步：执行脚本

```bash
python scripts/generate_summary.py --photo-dir <照片目录> --output <输出xlsx路径> --name <楼栋名>
```

**完整参数**：

```
--photo-dir   照片文件夹路径（必填，支持子目录递归扫描）
--output      输出Excel文件路径（必填）
--name        楼栋/区域名称（必填，如"3栋"）
--img-size    嵌入图片最长边像素（默认1600，0=不缩放）
--ocr-size    OCR缩略图最长边像素（默认800）
--sort        排序方式: desc=降序（默认）, asc=升序, none=不排
```

**注意**：
- Windows PowerShell 需设置 `$env:PYTHONUTF8="1"` 后再运行
- OCR引擎首次加载约需30秒
- 每张照片OCR约2-3秒，200张约10分钟
- 如果照片数量超过200张，脚本内置每50张自动GC防止内存溢出

### 第3步：检查结果

脚本完成后检查：
1. Excel文件是否生成，文件大小是否合理
2. 日志中是否有 `cannot parse` 或 `no content recognized` 的记录
3. 打开Excel确认照片清晰度和户号正确性

## 支持的水印格式

脚本自动识别3种水印格式（详见 `references/watermark_patterns.md`）：

1. **蓝色施工水印**：`施工内容 XXXX` 或 `施I内容 XXXX`
2. **橙色巡检水印**：`问题备注：X号楼XXXX` 或 `问题备注：X-XXXX`
3. **微信水印（兜底）**：`X-XXXX描述`

## Excel输出格式

| 列 | 内容 | 说明 |
|----|------|------|
| A | 序号 | 自动编号 |
| B | 楼栋号 | 如"3栋" |
| C | 户号 | 如"2602"，降序排列 |
| D | 问题描述 | 如"厨房墙砖空鼓" |
| E | 照片 | 嵌入原图（最长边1600px） |

- 表头蓝色背景白字，冻结首行
- 戶号降序排列，无法识别的排最后

## 遇到新水印格式时

1. 用调试脚本对单张照片打印OCR原始文本
2. 找出可稳定匹配的正则特征
3. 在 `scripts/generate_summary.py` 的 `extract_watermark_info()` 中增加新模式
4. 同步更新 `references/watermark_patterns.md`

## 依赖

- Python 3.8+
- easyocr, openpyxl, Pillow, numpy
