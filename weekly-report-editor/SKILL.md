# 周报区域自动排版 + 自动扩行编辑器

当用户要往《璀璨云著A地块维修周报》的某个区域"喂数据"，且希望**自动套用模板样式 + 数据超行时自动插行下移**，使用本 skill。

## 核心脚本

`weekly_report_editor.py`（位于 `d:\WorkBuddyClaw\weekly_report_editor.py`）。
如当前工作目录不同，先复制到项目目录或直接用绝对路径调用：

```python
import sys
sys.path.insert(0, r"d:\WorkBuddyClaw")
from weekly_report_editor import add_rows

# 风险预警：加一条（level 决定等级文案；seq 缺省自动顺延）
add_rows("周报.xlsx", "风险预警", [
    {"level": "中", "scope": "1-901", "risk": "风险事项描述…", "action": "处置建议…"}
])

# 协调事项：加一条（seq 可选，缺省顺延）
add_rows("周报.xlsx", "协调事项", [
    {"topic": "二十冶维修/1-901", "content": "事项内容…", "handle": "处置建议/请项目公司…"}
])

# 下周计划：加一条
add_rows("周报.xlsx", "下周计划", [
    {"label": "下周持续", "unit": "二十冶维修", "detail": "安排XX维修…剩余N条/单位"}
])

# 销项明细 / 剩余工程量：加一条（单行文本）
add_rows("周报.xlsx", "销项明细", [{"text": "门窗：38条  |  土建：3条"}])
add_rows("周报.xlsx", "剩余工程量", [{"text": "油漆：43条  |  瓦工：10条"}])
```

## 区域字段速查

| 区域 | 字段 | 说明 |
|------|------|------|
| 风险预警 | level, scope, risk, action（seq 可选） | level 取 "高"/"中"，红底白字；scope=户号/范围 |
| 协调事项 | topic, content, handle（seq 可选） | topic=单位/主题，content=事项，handle=处置 |
| 下周计划 | label, unit, detail | label=下周持续/视情，unit=单位，detail=安排… |
| 销项明细 | text | 单行文本（C:J 合并） |
| 剩余工程量 | text | 单行文本（D:J 合并） |

## 行为

- 自动克隆该区域参照行样式（字体/对齐/边框/底色/行高），按等级或交替底色排版。
- 预留行未满 → 填入空行；预留行已满 → **在区域末尾前自动插入新行**，并把下方所有区域 + 日期行整体下移，合并区同步重建。
- 默认就地保存（`save=True`）。

## ⚠ 必读注意事项（踩坑经验）

1. **改前先关 Excel**：文件被占用会写锁失败。
2. **模板含反向合并坐标**（如 `J:H`、`F:B`）：本脚本已内置全局正向归一化 + 写值前清缓存 + 合并用"移除+正向 add"（不用 `unmerge_cells`，否则 openpyxl 报 `_cells KeyError` 或 `MergedCell value read-only`）。**不要试图用 `unmerge_cells` 处理本模板。**
3. **自测务必每区域独立副本 + 从原始文件捕获参照签名对比**；连续写同一文件会因插入位移顶歪参照行，导致样式"误判不一致"。
4. 重要文件先备份再跑。

## 验证

- 单区域单条：`_selftest()`（复制真实文件到临时副本，五区域各喂一条，校验字体/对齐逐列一致 + 合并正确）。
- 多行批量：`test_multiline.py`（风险+3、协调+4，校验插入行号/样式/日期行下沉）。
